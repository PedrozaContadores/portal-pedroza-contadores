# Portal Pedroza Contadores - Hotfix 2.0.2

## Objetivo

Corrigir a validacao automatica da camada de protecao publicada na versao 2.0.1 e tornar a pagina de Termos de Uso acessivel pelo rodape do portal.

## Correcoes

- Leitura segura de `version.json` com ou sem BOM UTF-8.
- Compatibilidade com versao armazenada em JSON ou texto simples.
- Atualizacao do GitHub Actions para Node.js 22.
- Link visivel para `Termos de Uso` no rodape das paginas.
- Atualizacao dos marcadores tecnicos para a versao 2.0.2.
- Validacao local quando Node.js estiver instalado.
- Backup automatico antes da aplicacao.

## Escopo preservado

O hotfix nao altera a identidade visual, as calculadoras, as pesquisas, as bases tributarias nem as funcoes homologadas do Portal 2.0.1.
